Xác nhận hủy đơn

Bắt đầu sử dụng

Giao diện đọc dữ liệu CSV từ chương trình C++ khi mở qua server.

  1. Vào Sản phẩm để thêm sản phẩm, lọc loại thiết bị và thương hiệu. Bấm tên sản phẩm để sửa, nhập/xuất kho hoặc xóa.
  2. Vào Đơn hàng để lọc trạng thái, sắp xếp và xử lý đơn ưu tiên tiếp theo. Bấm mã đơn để xem lịch sử, chuyển trạng thái hoặc hủy.
  3. Dùng ô tra đúng mã phía trên để tìm sản phẩm hoặc đơn hàng. Với khoảng giá, nhập hai đầu khoảng rồi bấm Tìm khoảng giá.
  4. Vào Cảnh báo kho để xem hàng hết hoặc dưới ngưỡng.

Mở http://127.0.0.1:8080 sau khi chạy dsa_server để tạo đơn, chuyển trạng thái và hủy đơn. Các thao tác gọi core C++ và lưu CSV. Mở file HTML trực tiếp chỉ xem dữ liệu mẫu.
